# Паспорт шаблона разработки «Штампы»
## Возможности решения
Решение представляет набор функциональности по настройке и установке штампов на версии документов. Настройка позволяет в удобном для пользователя виде настроить расположение штампа на документе: первая страница, последняя, каждая страница, указать позицию расположения на странице, задать размер. Доступна настройка для настройки работы со шрифтами, кеглем и цветом, пример демонстрирует на отличия работы со шрифтами в Windows и Linux системах, доступно для текстового штампа и штампа с отрисовкой через SkiaSharp. Позволяет работать со штампами произвольного формирования, при помощи прикладной логики, штампов в виде BarCode128, QRCode, или загруженных в виде изображений. Присутствует возможность создания множества настроек под разные типы документов, для автоматического определения необходимых настроек штампа.

## Состав решения
1.	Модуль Штампы (StampModule).
2.	Справочник Настройки штампов (StampSettings).
3.	Изолированная область (GenerateStampArea) 
4.	Используемые внешние библиотеки: iTextSharp.dll – версия 5.5, SkiaSharp.dll – версия 3.116.1.0 (соответствует используемой библиотеке модуля Docflow в Directum RX 26.3).
## Варианты расширения функциональности на проектах
1.	Расширение возможностей настройки штампов, таких как введение информации для кодирования в BarCode128 и QRCode.
2.	Обработка установки множественных штампов на документах, с указанием матрицы расположения.
3.	Создание публичной или новой версии документа по результату формирования штампа.
4.	Добавление в работу решения новых штампов, например, EAN13, Aztec, DataMatrix.
5.	Формирование оттисков с реалистичными эффектами, средствами SkiaSharp.
6.	Формирование комбинированных штампов, используя наборы примеров, формирование оттисков с текстом и QR содом, а так же лого компании.
## Архитектурно неочевидные моменты
1.	В справочнике «Настройки штампов», при загрузке штампа в виде стороннего изображения, введено ограничение на загрузку файлов в формате JPG и PNG. При необходимости можно расширить набор форматов, с учётом поддержи их работы с iTextSharp, использующейся для установки на PDF версию документа. При загрузке стороннего изображения, производиться определение оригинального размера картинки, выводится пользователю и доступно для изменения.
2.	Вся обработка создания и установки штампов реализована в изолированной области, с передачей настроек штампа в виде структуры.
3.	Для примера демонстрации возможностей запуска, реализовано действие на обложке модуля «Установка штампа», в группе «Пробный запуск».
4.	Решение производит изменение последней версии документа, в формате PDF. При отсутствии версии в нужном формате, запускает преобразование существующей версии в PDF, используя методы конвертации модуля «Документооборот». Преобразованное тело документа заносится новой версией, после обрабатывается установка штампа.
5.	Обработка каждого вида штампа реализована в отдельной изолированной функции, представляя более удобный подход к их использованию и модификации, при использовании на реальных проектах стоит рассматривать переопределение логики, вынесение обработки в изолированный код, в изолированных функциях оставлять только методы обращения к обработке.
6.	Библиотека iTextSharp.dll не имеет поддержки на .Net Core и .Net6+, но в рамках тестовых и проектных практик проблем с работой на Directum RX 26.3 не выявлено, в дальнейшем развитии решения будет рассматриваться уход от использования данной библиотеки.
